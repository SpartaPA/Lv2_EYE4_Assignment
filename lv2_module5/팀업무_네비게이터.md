|---|---|---|
| `camera_node` | 통합 | RealSense RGB/Depth 데이터 제공 |


```text
/camera_node
/perception_node
/control_node
/opencr_node
```

# 5. Perception → Control

## Target Information

인지 결과는 제어에서 사용할 수 있도록 **표준 ROS 2 메시지**로 전달한다.

```text
Topic:
/perception/target

Type:
geometry_msgs/msg/PointStamped

Publisher:
perception_node

Subscriber:
control_node
```

### 의미

```text
point.x = X 위치 [m]
point.y = Y 위치 [m]
point.z = Z 위치 [m]
```

좌표계는 반드시 팀에서 사용하는 Camera Frame 기준을 확인한 후 고정한다.

예:

```text
/perception/target

geometry_msgs/msg/PointStamped
├── header
│   ├── stamp
│   └── frame_id
│
└── point
    ├── x
    ├── y
    └── z
```

예시:

```text
x = 0.15
y = -0.08
z = 0.72
```

의미:

> 카메라 좌표계에서 퍽이 `(0.15, -0.08, 0.72)m` 위치에 있음.

# 6. Control → OpenCR

## 이동 명령

```text
Topic:
/control/cmd_vel

Type:
geometry_msgs/msg/Twist

Publisher:
control_node

Subscriber:
opencr_node
```

메시지 구조:

```text
geometry_msgs/msg/Twist

linear.x
linear.y
linear.z

angular.x
angular.y
angular.z
```

차량 이동에는 기본적으로:

```text
linear.x
angular.z
```

를 사용한다.

예:

```text
linear.x  = 0.20
angular.z = 0.00
```

→ 전진

```text
linear.x  = 0.00
angular.z = 0.50
```

→ 제자리 회전

# 7. OpenCR → ROS 2

OpenCR의 모터 상태가 필요할 경우 다음 인터페이스를 사용한다.

```text
Topic:
/motor/state

Type:
sensor_msgs/msg/JointState

Publisher:
opencr_node

Subscriber:
control_node
```

메시지:

```text
sensor_msgs/msg/JointState

name[]
position[]
velocity[]
effort[]
```

예:

```text
name:
- left_wheel
- right_wheel

position:
- ...
- ...

velocity:
- ...
- ...
```

이를 이용해 제어 측에서 모터 상태를 확인할 수 있다.

# 8. 전체 Interface Table

| 방향 | Topic | Message Type | Publisher | Subscriber |
|---|---|---|---|---|
| Camera → Perception | `/camera/color/image_raw` | `sensor_msgs/msg/Image` | `camera_node` | `perception_node` |
| Camera → Perception | `/camera/depth/image_raw` | `sensor_msgs/msg/Image` | `camera_node` | `perception_node` |
| Perception → Control | `/perception/target` | `geometry_msgs/msg/PointStamped` | `perception_node` | `control_node` |
| Control → OpenCR | `/control/cmd_vel` | `geometry_msgs/msg/Twist` | `control_node` | `opencr_node` |
| OpenCR → Control | `/motor/state` | `sensor_msgs/msg/JointState` | `opencr_node` | `control_node` |

# 9. ROS 2 Interface Dependency

각 Node의 의존성은 다음과 같다.

```text
camera_node
├── sensor_msgs/msg/Image
└── std_msgs/... 필요 시

perception_node
├── sensor_msgs/msg/Image
└── geometry_msgs/msg/PointStamped

control_node
├── geometry_msgs/msg/PointStamped
└── geometry_msgs/msg/Twist

opencr_node
├── geometry_msgs/msg/Twist
└── sensor_msgs/msg/JointState
```

따라서 Python package의 `package.xml`에는 최소한 다음 ROS 2 패키지가 필요하다.

```xml
<depend>rclpy</depend>
<depend>sensor_msgs</depend>
<depend>geometry_msgs</depend>
```

# 10. Interface별 담당

## 👁️ 인지

구현해야 하는 부분:

```text
SUBSCRIBE
/camera/color/image_raw
sensor_msgs/msg/Image

/camera/depth/image_raw
sensor_msgs/msg/Image
```

그리고:

```text
PUBLISH
/perception/target
geometry_msgs/msg/PointStamped
```

즉:

```text
RGB + Depth
     ↓
인지 알고리즘
     ↓
Target Point
```

# 11. ⚙️ 제어

구현해야 하는 부분:

```text
SUBSCRIBE
/perception/target
geometry_msgs/msg/PointStamped
```

그리고:

```text
PUBLISH
/control/cmd_vel
geometry_msgs/msg/Twist
```

필요하면:

```text
SUBSCRIBE
/motor/state
sensor_msgs/msg/JointState
```

즉:

```text
Target
  ↓
제어 알고리즘
  ↓
cmd_vel
```

# 12. 🔗 통합

통합 담당은 **Topic을 직접 계산하는 것이 아니라 Node 사이의 연결을 책임진다.**

주요 작업:

```text
camera_node
    ↓
Camera Topics
    ↓
perception_node
    ↓
Target Topic
    ↓
control_node
    ↓
cmd_vel
    ↓
opencr_node
```

통합 담당의 주요 파일:

```text
ros2_ws/src/realsense_tracker/
├── realsense_tracker/
│   ├── camera_node.py
│   └── opencr_node.py
│
├── launch/
│   └── tracker.launch.py
│
└── config/
    └── tracker.yaml
```

# 14. Interface 변경 규칙

ROS 2 Interface는 팀 전체의 **계약(Contract)**이다.

예를 들어:

```text
/perception/target
```

을

```text
/perception/target_position
```

으로 임의 변경하면 안 된다.

변경이 필요한 경우:

```text
변경 제안
    ↓
인지 + 제어 + 통합 협의
    ↓
검토
    ↓
Interface 확정
    ↓
각 Node 수정
    ↓
통합 테스트
```

# 17. 🧭 한 줄 네비게이터

```text
👁️ 인지
RGB/Depth → 퍽 탐지 → /perception/target

⚙️ 제어
/perception/target → 제어 판단 → /control/cmd_vel

🔗 통합
Camera → Perception → Control → OpenCR 전체 연결

🔍 검토
Node → Topic → Message → Hardware → Mission 전체 검증
```

> **ROS 2 Topic과 Message Type은 팀 전체가 공유하는 인터페이스 계약이다. 구현 파트는 이 계약을 기준으로 자신의 Node를 개발한다.**
