# 영상·bag 및 재현 상태 — 2026-10-08

## 제공된 영상 링크

[팀 시연 영상 공유 폴더](https://drive.google.com/drive/folders/1tOibtMF1Q7g7146O-sqSVVbWGnd0sBoK?usp=sharing)

공유자 안내: 발제 조건에 부합하는 영상이 필요하면 재촬영이 필요할 수 있음. 문서 작성 시 폴더 내용 접근 실패로 개별 영상은 미열람이다. 파일명·길이·촬영 환경·Kp·가림 횟수·정지 시각·시험 commit은 확인하지 못했다. 이 링크만으로 필수 검증 통과를 판정하지 않는다.

## bag 기록·재현

| 항목 | 상태 | 부족한 증거 |
|---|---|---|
| 성공 10~30초 bag | 이번 자료 미제공 | metadata.yaml·데이터 파일·토픽 목록·기간 |
| 소실/복귀 10~30초 bag | 이번 자료 미제공 | 같은 항목, 영상·추적 CSV 연결 |
| SHA-256·설정·commit | 최신 제어 PR에서 archive/hash 존재 보고 | 실제 파일·해시·대응 실행 ID |
| 입력 재처리 | 결과 미확인 | 컬러 재생 후 새 인지 결과와 원본 비교 |
| 출력 재분석 | 기능 구현 보고만 확인 | bag 재생 CSV·분석 결과·비교 |
| 다른 팀원의 재현 | 기록 미제공 | 확인자·날짜·환경·실행 commit·결과 |

bag은 MP4 영상과 다르다. 저장된 `/target`을 재생하는 것은 새 영상 검출이 아니다. 현재 자료로 재현 성공/실패를 판단할 수 없다. 기존 절차는 저장소 README 18~20절을 참고하되 실제 재생은 모터 출력 비활성화와 격리 ROS 도메인에서 진행한다.

## 검증하지 못한 이유

구동 준비·중립 위치·LIMIT·카메라 USB 문제가 회고에 기록되어 있다. 최신 LIVE 개선 보고와 제출 원본 증거가 연결되지 않아 재현의 기준 버전도 확정하지 못했다. bag을 실제로 기록하지 않았는지, 기록 후 제출하지 않았는지는 자료만으로 구분할 수 없다.
