## 범위 혼동 방지

- 노트북 인지 평가 ≠ Raspberry Pi 폐루프 성능.
- 카메라 토픽 약30Hz 관찰 보고 ≠ Pi 인지 처리 FPS 정량 측정.
- TRACKING·stop=false ≠ 실제 ARM·모터 회전의 증거.
- DRY/PTY ≠ LIVE 실기, 보드 단독 시험 ≠ ROS 전체 체인 시험.
- 실행 스크립트 ≠ 성공 실행 로그, PR 설명 ≠ 원본 측정값.
- 출력 기록 재생 ≠ 입력 영상을 새로 검출하는 재처리.
- 기존 ZIP ±80counts 및 bridge0.15초 ≠ 최신 최종 설정 확정값.

최신 제어/통합 PR은 진행 사실의 팀원 보고로 보존한다. 원본 부족을 무조건 미실행으로 표기하지 않는다. 개별 결과는 [report.md](../report.md)와 [시험 상태 CSV](../results/logs/verification/verification_results.csv)를 참조한다.
